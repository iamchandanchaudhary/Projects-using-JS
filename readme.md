## ⭐ Featured Projects

### 🎮 Simon Says Game
A classic memory game where players must repeat an increasingly complex sequence of colors and sounds.

**Features:**
- Progressive difficulty levels
- Visual and interactive feedback
- Score tracking
- Game over detection with score display

**Concepts Demonstrated:** Event listeners, Arrays, Game state management, setTimeout

---

### ✅ Todo App
A simple yet functional task management application.

**Features:**
- Add new tasks
- Delete completed tasks
- Clean and minimal UI

**Concepts Demonstrated:** DOM manipulation, createElement, Event delegation

---

### 🐕 Random Dog Image Generator
Fetches and displays random dog images using the Dog CEO API.

**Features:**
- Generate random dog images on click
- Loading state handling
- Clear image functionality

**Concepts Demonstrated:** Axios HTTP client, Async/Await, External API integration

---

### 🎲 Random Fact Generator
Displays random cat facts fetched from an external API.

**Features:**
- Generate facts on button click
- Display multiple facts in a list
- Error handling

**Concepts Demonstrated:** Fetch API, Async/Await, Try-Catch error handling

---

### ❌⭕ Tic Tac Toe
Classic two-player game with win detection.

**Features:**
- Two-player gameplay
- Win/draw detection
- Game reset functionality

**Concepts Demonstrated:** 2D game logic, Conditional rendering, State management

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Code editor (VS Code recommended)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/Projects-using-JS.git
   ```

2. **Navigate to a project folder**
   ```bash
   cd Projects-using-JS/Simon-Says-Game
   ```

3. **Open in browser**
   - Open `index.html` directly in your browser, or
   - Use a live server extension in VS Code
